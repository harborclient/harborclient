# @harborclient/core

Platform-neutral HarborClient engine: types, request orchestration helpers, and shared utilities.

This package is the shared runtime used by the HarborClient GUI, CLI, and storage adapters. It has no Electron, Redux, or browser dependencies — hosts inject transport, persistence, and UI-specific services.

> [!NOTE]
> User-facing product docs live at [harborclient.com](https://harborclient.com/). This site documents the `@harborclient/core` library for contributors and integrators.
